# Safari Sentences

Free sentence typing game by [Typing Games Free](https://typinggamesfree.io/).

Guide an explorer across the African savanna by typing ten sentences exactly, with capital letters, punctuation and spaces, in 90 seconds. A wrong key never counts, so watch your Shift key and your full stops. At the end you get your score, WPM, accuracy and best score.

## Files

- `index.html` - the whole game (logo embedded, no dependencies)
- `assets/logo.webp` - original Typing Games Free logo
- `thumbnail-512.webp` / `.png` / `.jpg` - 512x512 game thumbnail (all under 90 KB)

Desktop keyboard required.

## Play on GitHub Pages

1. Upload this folder to a GitHub repository.
2. Go to **Settings -> Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
3. The game will be live at `https://<username>.github.io/<repo>/`.
